# OCMUI Workflows

Custom workflows for the OCMUI/UHC Portal team.

## Workflows

- **bugfix/** - Bug fix workflow for Interruption Catcher duties and general bug fixing

## Loading Workflows in ACP

Load workflows as Custom Workflows using:

| Field | Value |
|-------|-------|
| **URL** | `https://github.com/RedHatInsights/ocmui-workflows.git` |
| **Branch** | `main` |
| **Path** | `{workflow-name}` |
